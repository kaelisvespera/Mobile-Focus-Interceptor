# 移动端优化小工具

主要优化 SillyTavern 和 TauriTavern 的移动端界面与输入体验，部分优化也适用于电脑端。

## TauriTavern 2.4.0

在 TT 中打开「扩展 → 安装扩展」，粘贴 `https://github.com/kaelisvespera/Mobile-Focus-Interceptor`，选择 `main`，安装后重载。如果已经安装原版，请先在扩展管理中卸载，保留扩展数据，再安装此 fork。

在 TT 中，插件保留长文本粘贴、Token 计数器、角色收藏头像缓存，以及默认关闭的重新生成确认和页面离开确认。长文本合并时输入框保持可见，内置助手沿用自己的粘贴处理。

聊天框聚焦、键盘视口和顶层及普通抽屉动画由 TT 管理。插件的面板优化用于预设提示词弹窗和角色头像区。TT 样式表由宿主维护。

启用离开确认后，Android 系统返回先由 TT 处理。只有即将退出应用时才弹出确认。刷新和关闭页面的确认取决于 WebView 的 `beforeunload` 支持。

在扩展设置的「防误触保护」中开启「返回主页面前确认」，即可在系统返回或打开菜单点击「关闭聊天」时选择继续聊天或回到主页面。这个开关独立于退出应用确认，默认关闭。

适配基线为 TT 2.4.0 热修版 [`fff9af0`](https://github.com/Darkatse/TauriTavern/releases/tag/v2.4.0)。原项目见 [akira59851/Mobile-Focus-Interceptor](https://github.com/akira59851/Mobile-Focus-Interceptor)。

## SillyTavern 功能

### 输入与键盘

- **防止键盘频繁弹出**：阻止虚拟键盘自动弹出，仅主动点击输入框时允许唤起。
- **优化长文本粘贴卡顿**：减少通过虚拟键盘粘贴大量文本时的延迟与卡顿。
- **防止浮窗键盘顶起界面**：外部浮窗应用唤起键盘时，ST 主界面不再被顶起。
- **上层输入时锁定底层布局**：在世界书、角色卡等界面中呼出键盘时，锁定底层主界面不被顶起，减少不必要的布局变动与卡顿。

### 界面与性能（双端）

- **优化键盘开合与界面流畅度**：解决打开抽屉或弹窗后，手机键盘弹出/收起持续卡顿以及电脑端面板操作迟缓的问题。
- **优化面板开合卡顿**：让抽屉与折叠区更快展开并瞬间收起，减少画面掉帧与跳动。
- **角色收藏头像缓存**：减少重复打开角色管理面板时不必要的扫描和刷新。
- **优化 Token 计数器卡顿**：优化长文本的分词高亮渲染，避免页面卡顿与假死，分词结果过长时分段加载。

### 防误触保护

- **离开页面弹窗确认（双端）**：刷新、关闭或侧滑返回前弹窗确认，防止误触导致页面重载。
- **重新生成/备选回复弹窗确认**：重新生成或生成备选回复前弹窗确认，防止误触丢失内容或消耗额度。

## SillyTavern 安装与使用

复制下方链接，在 ST 的「扩展」-「安装扩展」中粘贴并安装，完成后刷新页面即可：

`https://github.com/akira59851/Mobile-Focus-Interceptor`

性能优化项默认开启，防误触确认项默认关闭。可在「扩展设置」面板中分别控制各项功能的开启与关闭，设置即时生效。

如需排查问题，可在 `index.js` 顶部将 `MFI_DEBUG` 改为 `true` 开启调试日志。

## 其他说明

- 原版的测试环境为 `SillyTavern 1.18.0`。此 fork 额外适配 TauriTavern 2.4.0。
- 本插件代码由 AI 生成与实现。
- 仅适用于移动端的功能不会在电脑端加载。

- 新增 TT「返回主页面前确认」，覆盖关闭聊天菜单和系统返回到主页面的操作。

### [v1.4.1-tt.1]

### [v1.4.0] - 2026-11-22

**[新增]**
- 扩展设置面板：支持在扩展设置中独立控制各项优化功能的启停（区分手机端与电脑端），修改即时生效。
- 上层输入时锁定底层布局：在世界书、角色卡、设置等界面输入时锁定底层聊天主界面，减少布局重算。

- 防误触保护：新增「离开页面弹窗确认」（支持浏览器原生及 PWA 应用侧滑返回拦截）与「重新生成/备选回复弹窗确认」（默认关闭）。

**[优化]**
- Token 计数器优化调整为仅在对应面板打开期间按需启用。
- 优化长文本粘贴拦截与页面生命周期管理逻辑，提升稳定性。
